# Banking AI Design Assignment

The **two-page deliverable** is: `00_Banking_AI_Design_Overview.docx` (one printable page) + `09_Banking_AI_Design_Architecture.drawio` (one diagram page). The Markdown overview `01_Banking_AI_Design_Overview.md` is the easy-to-edit Confluence/Obsidian version.

**Supporting design files:** `02_Banking_AI_Design_Principles.md`, `03_Banking_AI_Design_ADR_01_LLM.md`, `04_Banking_AI_Design_ADR_02_Vector_Search.md`, `05_Banking_AI_Design_ADR_03_Processing_Mode.md`, `06_Banking_AI_Design_Review_Checklist.md`, `07_Banking_AI_Design_Policy_Guardrail.py`, `08_Banking_AI_Design_Architecture_Policy.json`.

**How to edit:** Word/Google Docs for `.docx`, any text editor for `.md` / `.py` / `.json`, and https://app.diagrams.net/ for `.drawio` (File → Open From → Device).

**Business result:** An *illustrative*, unverified SAR 22,000 incremental net contribution per monthly pilot cohort. It is not a claim of achieved or forecast bank earnings; run a randomized controlled test and finance validation before use.
