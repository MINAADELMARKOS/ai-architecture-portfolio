# Editable Banking AI Mini-Project Files

The **two-page deliverable** is: `00_One_Page_Wiki.docx` (one printable page) + `09_Banking_Simple_Architecture.drawio` (one diagram page). The Markdown wiki `01_One_Page_Wiki.md` is the easy-to-edit Confluence/Obsidian version.

**Supporting, individually editable requirement files:** `02_Principles_Explained.md`, `03_ADR_01_LLM.md`, `04_ADR_02_Vector_Search.md`, `05_ADR_03_Batch_or_Real_Time.md`, `06_ARB_Checklist.md`, `07_Guardrail_CI.py`, `08_Architecture_Policy.json`.

**How to edit:** Word/Google Docs for `.docx`, any text editor for `.md` / `.py` / `.json`, and https://app.diagrams.net/ for `.drawio` (File → Open From → Device). The source slide deck is not modified.

**Business result:** An *illustrative*, unverified SAR 22,000 incremental net contribution per monthly pilot cohort. It is not a claim of achieved or forecast bank earnings; run a randomized controlled test and finance validation before use.
